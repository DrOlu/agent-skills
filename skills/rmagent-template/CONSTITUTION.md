# RMAgent constitution — 14 rules

Print this. Put it in the PR. Do not edit the rules to fit a dashboard.

1. **Watch only (Phase 0).** No actuate in the question set.
2. **Allowlisted questions only.** `ask()` refuses unknown names and `actuate`.
3. **Capped answers (32 KB).** Oversized → hole, never a truncated lie.
4. **A hole is an answer.** `{asked, empty, why}` — same shape as a hop.
5. **Never trust “no findings” until the witness can see.** `*attest` + `blind_check`.
6. **On-device rings, not shipped lakes.** Cases are megabytes; events stay put.
7. **Context propagates; data does not.** Depth ≤ 8, fan-out ≤ 3.
8. **Credentials never in inventory, skill, or case.**
9. **Your estate only.** Else hole.
10. **No tight retry on a silent host.** Two missed attests = Critical.
11. **Secrets / PAN / prompts never stored raw.** Mask or names-only.
12. **Persistent rings are MOP.** Dry-run default, `--apply`, tested `--teardown`.
13. **Honest fidelity gaps.** No silent degrade that looks like Sysmon.
14. **Keep the existing sensor.** The knock is not a rip-and-replace.

**Lake test:** if a new operator would `scp` home a file that grows without
bound, the skill has failed.

**One-sentence test:**

> Follow **one GRAIN** across **SCOPE** without a **WAREHOUSE**,
> by asking **QUESTIONS** on devices we administer.

If you cannot fill it, you have a dashboard idea, not an rmagent skill.
